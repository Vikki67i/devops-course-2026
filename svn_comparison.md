# Сравнение Git и SVN

## 1. Почему создание веток дешёвое в Git и дорогое в SVN?

В Git ветка — это лёгкая ссылка на коммит, поэтому её создание занимает очень мало времени и места.

В SVN ветвление связано с операциями над репозиторием, поэтому оно обычно требует больше ресурсов и может быть более трудоёмким.

## 2. Можно ли сделать commit в SVN без интернета? Почему?

Да, если SVN-репозиторий находится локально или доступен по сети без необходимости выхода в интернет. Но для удалённого центрального SVN-репозитория обычно требуется подключение к нему.

## 3. В каких случаях SVN всё ещё может быть предпочтительнее Git?

SVN может быть удобнее в проектах, где нужна централизованная модель контроля версий, строгий контроль доступа к отдельным каталогам или уже используется существующая инфраструктура SVN.
