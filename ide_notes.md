# Git в VS Code

## Что удобно в VS Code

1. Удобно видеть изменённые файлы в Source Control.
2. Можно сразу просматривать Diff изменений.
3. Можно делать commit и синхронизировать изменения с GitHub прямо из интерфейса.

## Что удобнее в терминале

В терминале удобнее выполнять сложные команды Git и точно контролировать каждое действие.
